Praktikum Python - Kali Linux

Deskripsi

Proyek ini dibuat untuk memenuhi tugas praktikum Python, virtual environment, dan Git menggunakan Kali Linux.

Program

- "halo.py": Menampilkan salam, nama, dan umur pengguna.
- "tampil.py": Menampilkan tabel informasi menggunakan library Rich.
- "requirements.txt": Daftar library Python yang digunakan.
- ".gitignore": Daftar file dan folder yang tidak perlu dimasukkan ke Git.

Teknologi

- Python
- Virtual Environment ("venv")
- Git dan GitHub
- Library Rich

Cara Menjalankan

Aktifkan virtual environment:

source .venv/bin/activate

Jalankan program salam:

python halo.py

Jalankan program tabel:

python tampil.py

Tujuan

Mempelajari dasar Python, pengelolaan library, version control menggunakan Git, branch, merge, dan penyimpanan proyek di GitHub.
